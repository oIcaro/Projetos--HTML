# Projeto Apresentação

Página de apresentação em HTML puro, construída como desafio prático do módulo de HTML. O tema escolhido foi um perfil do meu gato, Sirius, com uma breve descrição e uma lista de links para redes sociais.

O foco do desafio era praticar a marcação de conteúdo e o uso de links externos, sem recorrer a folhas de estilo.

## Conteúdo da página

- Título e subtítulo hierarquizados (`<h1>`, `<h2>`)
- Foto de perfil em formato circular
- Parágrafos descritivos com destaques em negrito e itálico
- Lista de links para redes sociais (Instagram, YouTube, Twitter e Reddit), cada um acompanhado de seu ícone

## Conceitos praticados

- Hierarquia de títulos e estruturação de texto (`<h1>`, `<h2>`, `<p>`)
- Formatação semântica inline com `<b>` e `<i>`
- Inserção de imagens (`<img>`) com texto alternativo
- Links externos com `<a href>` e abertura em nova aba via `target="_blank"`
- Imagens dentro de links, formando ícones clicáveis
- Listas não ordenadas (`<ul>`, `<li>`)
- Favicon através de `<link rel="shortcut icon">`
- CSS inline pelo atributo `style` para recortar a imagem em círculo (`border-radius` e `object-fit`)
