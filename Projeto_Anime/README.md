# Projeto Anime

Página em HTML puro com uma lista pessoal de animes favoritos, organizada por categoria (Shounen, Romance e Fantasia). Desenvolvida como desafio prático do módulo de HTML, com foco em listas aninhadas e formatação de texto.

## Conteúdo da página

- Título e introdução ao tema
- Lista numerada de categorias, cada uma contendo uma sublista de animes
- Sublistas com numeração alfabética (`a, b, c...`) e continuidade de contagem entre elas

## Conceitos praticados

- Listas ordenadas aninhadas (`<ol>` dentro de `<ol>`)
- Customização da numeração com o atributo `type` (numeração alfabética)
- Continuidade da contagem entre listas separadas com o atributo `start`
- Formatação semântica inline com `<b>` e `<i>`
- Organização de conteúdo dentro de uma `<div>` com classe (`hero`)
- Vínculo com folha de estilo externa (`css/style.css`)

## Estrutura de arquivos

```
Projeto_Anime/
├── index.html
└── css/
    └── style.css
```

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.
