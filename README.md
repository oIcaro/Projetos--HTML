# Projetos HTML

Repositório com projetos simples desenvolvidos durante meus estudos de HTML e CSS. Cada pasta contém um exercício prático focado em um conceito específico da construção de páginas web.

O objetivo aqui é registrar minha evolução no aprendizado e servir como material de consulta para revisar técnicas já praticadas.

## Tecnologias

- HTML5
- CSS3

## Projetos

| Projeto | Descrição | Conceitos praticados |
|---|---|---|
| [`Projeto_Unes`](./Projeto_Unes) | Site institucional de uma universidade fictícia, com três páginas interligadas (início, quem somos e contato) | Layout com tabelas, navegação entre páginas, formulários |
| [`Projeto_Apresentação`](./Projeto_Apresentação) | Página de apresentação pessoal com foto, descrição e links para redes sociais | Hierarquia de texto, imagens, links externos, favicon |
| [`Projeto_Anime`](./Projeto_Anime) | Lista pessoal de animes favoritos organizada por categoria | Listas ordenadas aninhadas, numeração customizada |

## Como visualizar

Clone o repositório:

\`\`\`bash
git clone https://github.com/oIcaro/Projetos--HTML.git
\`\`\`

Em seguida, abra o arquivo \`index.html\` da pasta do projeto desejado diretamente no navegador.
